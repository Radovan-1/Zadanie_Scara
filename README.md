## Workspace SCARA robota

Tento projekt sa zameriava na vizualizáciu pracovného priestoru SCARA robota:

- **2D vizualizácia**: Vykreslenie pracovného priestoru v prostredí `matplotlib` ako graf.
- **3D vizualizácia**: Simulácia a zobrazenie pracovného priestoru v prostredí `PyBullet`.
- Cieľom je presné znázornenie rozsahu pohybu a dostupných pozícií ramena SCARA robota v 2D aj 3D priestore.
